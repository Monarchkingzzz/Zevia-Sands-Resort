# 🌴 Zevia Sands Resort & Sanctuary

> **Where Sun-Drenched Sands Meet Turquoise Waters.**  
> An ultra-luxury, modern beachfront resort website designed for high-conversion hospitality client presentations.

## ✨ Features

- **🏝️ Real Sunlit Beach Aesthetics**: Curated high-resolution photography of overwater villas, crystal lagoons, white sand coastlines, and sunset bars.
- **🏛️ Editorial Luxury Typography**: `Cormorant Garamond` serif paired with modern, crisp `Plus Jakarta Sans`.
- **🛏️ Villa Collection**:
  - *Overwater Lagoon Villa* ($680/night)
  - *Beachfront Palm Villa* ($490/night)
  - *Horizon Infinity Villa* ($1,150/night)
- **🏊 40m Lagoon Infinity Pool & 2km Private Beach**: Sun loungers, palm canopies, and warm shallow reef.
- **🦞 Fresh Coastal Dining & Bars**: Floating pool breakfasts, beachfront open-flame lobster grill, and in-water swim-up cocktail bar.
- **🏄 Ocean Adventures**: Clear glass tandem kayaking, sea turtle reef snorkeling, sunset catamaran cruises, and beachside palm massages.
- **⚡ Streamlined Real-Time Booking Engine**: Date pickers, guest counters, instant price calculations, and confirmation voucher modal.
- **📱 100% Responsive & Zero Dependencies**: Lightweight, vanilla HTML5, CSS3, and ES6 JavaScript.

## 🚀 Live Preview & Quick Start

Simply open `index.html` or `zevia-sands-resort.html` in any modern web browser.

```bash
# Clone the repository
git clone https://github.com/Monarchkingzzz/Zevia-Sands-Resort.git

# Open the project
cd Zevia-Sands-Resort
start index.html
```
